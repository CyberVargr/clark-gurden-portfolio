## Mandatory portfolio review team

- This team review is a hard requirement for every portfolio review, planning, content, design, implementation, validation, publication, or deployment round. Do not skip it because a change appears small, repeats an earlier issue, or has already received one specialist's approval.

- Give every reviewer the same current task brief, factual guardrails, source manifest, and before-state evidence. Each reviewer must distinguish observed evidence, professional judgment, unresolved uncertainty, and required user confirmation.
- Run the team in waves if tool or concurrency limits prevent simultaneous review. Every required discipline must still report before the round is considered complete.
- The CEO / Orchestrator owns scope, resolves disagreements against the evidence and acceptance criteria, records rejected alternatives, and issues the final go/no-go. Do not use majority voting, forced consensus, or ceremonial agreement.
- Only one implementation owner may edit at a time. Reviewers and evaluators remain read-only. A fresh verifier that did not implement the changes must validate the completed result.
- No round may be represented as team-approved unless the final handoff identifies the disciplines consulted, material disagreements or uncertainties, the CEO decision, validation evidence, and any remaining blocker.
- This requirement persists for all future work performed in this repository unless Clark explicitly replaces it in writing. It does not authorize unsupported claims, broader scope, publication, pushing, deployment, or disclosure of private employer materials.
